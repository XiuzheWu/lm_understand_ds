# 推理轨迹标注规范（初版）

原始推理、最终回复、代码、工具结果分别保存。标注是后处理，不能改变第一阶段模型所见提示。

每条标注记录 run_id、turn_id、引用位置、标注者、置信度，以及：

- 假设及首次出现时点；是否已由原提示引导。
- 证据来源和可核验数值；实际执行的方法。
- 结果前预测与结果后解释，严格分开。
- 叙述与代码是否一致；是否错误引用工具结果。
- 反馈后修正、保留或放弃假设的理由。
- 证据等级：文本提及 / 代码实现 / 数值支持 / 独立行为验证。

核心片段人工核验；比较组隐藏配置身份，部分样本双人标注。不得用推理长度、假设数量或叙述流畅程度替代能力评分。

每个运行生成一份时间线报告，保留失败分支和未解决的问题。模型未输出的推理不得由标注者补写后冒充原记录。
